التخزين SQLite في /tmp/platform-ref.db (يُنشأ تلقائيًا ببيانة بذرة واحدة).

## الحدود
- تطبيق مرجعي مبسّط: تخزين SQLite مؤقت، بلا مصادقة، بلا ترقيم صفحات، تغطية المسارات الخمسة فقط.
