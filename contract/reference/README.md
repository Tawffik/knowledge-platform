# التطبيق المرجعي للمنصة (تنفيذ Instinct المرجعي)

**التاريخ:** ٢٦ نوفمبر ٢٠٢٦ — **الحالة:** تنفيذ مرجعي محلي لإثبات قابلية تنفيذ العقد، **ليس** تسليم الكارِف ولا بديلًا عنه. نسخة الكارِف تُقبل أو تُراجع بمقارنتها بهذا الأساس وبجناح القبول.

## نتيجة مقاسة (٠٠:١٩ EET)
جناح القبول test_contract_negative.py ضد هذا الخادم محليًا: **8/8 PASSED** (أول تشغيل فعلي للجناح ضد خادم حقيقي — قبلها كان 8 skipped بلا خادم). العقد قابل للتنفيذ كما هو مكتوب.

## التشغيل القابل للتكرار
```
pip install fastapi uvicorn
cd reference && uvicorn app:app --host 127.0.0.1 --port 8000
cd .. && python -m pytest test_contract_negative.py -v
```
التخزين SQLite في /tmp/platform-ref.db (يُنشأ تلقائيًا ببيانة بذرة واحدة).

## الحدود
- تطبيق مرجعي مبسّط: تخزين SQLite مؤقت، بلا مصادقة، بلا ترقيم صفحات، تغطية المسارات الخمسة فقط.
- FastAPI تولّد وثائق /openapi.json من الكود — قد تختلف تفاصيل شكلية عن مسودة العقد اليدوية؛ العقد اليدوي هو المرجع، والفروق تُراجع عند تسليم نسخة الكارِف.
