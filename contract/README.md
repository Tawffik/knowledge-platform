# Portfolio Platform — عقد API والاختبارات (تسليمة Instinct)

**التاريخ:** ٢٥ نوفمبر ٢٠٢٦ — **الحالة:** مسودة عقد في إطار تقسيم مقبول من الطرفين، لم يُعتمد نهائيًا. بناء محلي مجاني فقط؛ لا ريبو جديد ولا حسابات ولا استضافة بدون قرار المالك.

## الملفات
- `openapi.yaml` — مسودة عقد OpenAPI 3.1: مشاريع + خزنة معرفة + ليدجر + سجل مراجعات، بكيانات Evidence/MetricRun/VerificationLabel/ReviewRecord (المهارات مصفوفة وسوم نصية مباشرة على المشروع في نطاق MVP — لا سكيما SkillTag مستقلة).
- `test_contract_negative.py` — جناح pytest: ٦ حالات رفض سالبة (بلا مصدر، تصنيف غير صالح، بلا أمر تشغيل، مراجعة بلا سبب، قرار مراجعة خارج القائمة، سلاج غير صالح) + حالتا نجاح (شكل القائمة، /openapi.json). كل حالة سالبة تمر فقط إذا رفض الخادم الإدخال الفاسد بـ 400/422؛ قبوله = فشل حقيقي. بدون خادم تُتخطى الاختبارات (SKIP) بسبب مُعلن — غياب الخادم حالة تشغيل مُقاسة لا نتيجة متوقعة. تتحول لبوابة قبول للنسخة الأولى: ٨/٨ تمر مع خادم يطبق العقد.

## نتائج التنفيذ الفعلية (٢٥ نوفمبر ٢٠٢٦)
- `openapi-spec-validator` على openapi.yaml: **PASS** — لا أخطاء مواصفة (تحقق سكيما حقيقي، ليس مجرد تحليل YAML).
- `pytest`: جُمعت ٨ اختبارات، **٨ skipped / 0 passed / 0 failed** — لا خادم بعد؛ التخطي هو السلوك المُقاس المُعلن. لم تُختبر أي استجابة خادم فعلية بعد.

## تشغيل قابل للتكرار
```
python -m venv .venv && . .venv/bin/activate
pip install pytest httpx pyyaml
BASE_URL=http://127.0.0.1:8000 python -m pytest test_contract_negative.py -v
```
البيئة: python>=3.11. الافتراضي BASE_URL=http://127.0.0.1:8000.

## CI أوفلاين (مقترح للنسخة الأولى)
خطوة واحدة: lint (ruff) ثم الجناح أعلاه على خادم اختبار محلي (uvicorn على منفذ عشوائي، SQLite مؤقتة). بلا خدمات خارجية — يتوافق مع قيد صفر ميزانية.
